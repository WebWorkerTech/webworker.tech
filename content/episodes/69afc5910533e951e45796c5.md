<h2>节目简介</h2><p>2025年春节后第一期正式录制，辛宝、小白菜、瑞丰三位主播深度聊了聊最近火爆出圈的 OpenClaw（龙虾）。从技术产品到大众消费品，从国外一天9000个 star 到国内线下聚会遍地开花，甚至深圳政府都发文规范了。这个 AI Agent 到底有什么魔力？三位主播从爆火时间线、技术实现、实际使用体验、未来展望等多个角度，带你全面了解龙虾现象。</p><h2>大纲内容</h2><h3>1. 龙虾是什么？为什么叫龙虾？</h3><p>OpenClaw 是一个开源的 AI Agent，具备自主性能，能够自主完成任务。它可以接入 Telegram、Discord、飞书等即时通讯平台，24小时在线待命，随时听从指令帮你完成任务。</p><blockquote>"他现在的名字叫做 OpenClaw，其实就是一个开源的具备自主性能，能够自主完成一些任务的 AI agent。它可以接入各种即时通讯平台，例如 Telegram、Discord 以及飞书等，你可以在手机上操作它。" —— 瑞丰</blockquote><p>为什么叫龙虾？因为 OpenClaw 的 logo 上有一个龙虾的标志，而且"OpenClaw"这个英文名发音音节较多，在国内不易传播。小龙虾的红色 logo 非常醒目，又是动物形象，很容易制作成表情包。现在很多线下活动都会点小龙虾，一边吃蒜蓉小龙虾、麻辣小龙虾，一边聊 OpenClaw，氛围感直接拉满。</p><h3>2. 从0到15万 star：龙虾的爆火时间线</h3><p><strong>2025年1月24-25日</strong>：创始人 Peter 参加播客，项目在国外开始爆火，一天内获得9000多个 star。</p><p><strong>1月27日</strong>：Anthropic 向 Peter 发出侵权函，指出项目原名"ClawdBot"中的"Claude"与自家产品名称过于相似。这是第一次改名事件。</p><p><strong>1月28日</strong>：项目改名为"MoltBot"。同日，有人创建了一个名为 MoltBook 的社区平台（类似 Reddit 的论坛），规定只能通过 AI 在上面交流，让你的 OpenClaw 在上面发帖。</p><p><strong>1月29-30日</strong>：两天时间内，MoltBook 平台的帖子数量疯狂增长至3万多个，涌现大量有趣内容，推动 OpenClaw 持续爆火。项目 star 数在72小时内涨到6万多个。</p><p><strong>1月30日左右</strong>：项目再次改名，更名为如今的最终名称"OpenClaw"。这是第二次改名。</p><p><strong>2月上旬</strong>：话题在中国社区迅速引爆，几乎涵盖了中文推特、微博、知乎等所有平台。各地开始出现线下聚会。</p><p><strong>2月中下旬至3月</strong>：热度不降反升，北京、深圳、成都等地龙虾聚会遍地开花。深圳政府甚至发文规范 AI Agent 应用。项目 star 数涨到15万。</p><blockquote>"我本来以为最开始爆火后，过完年热度就会慢慢下去了，但没想到过完年之后热度还是越来越高。包括北京的、深圳的、成都的，看到好多个龙虾聚会，感觉热度还在持续。" —— 瑞丰</blockquote><h3>3. 技术上并不新，但为什么火了？</h3><p>从技术角度看，OpenClaw 并不算新东西，它是已有知识和工具的组合。但它踩中了几个关键风口：</p><p><strong>时机恰好</strong>：AI Agent 概念正热，大模型能力足够强，正好到了可以实用化的临界点。</p><p><strong>易用性强</strong>：可以在手机上通过 IM 平台操作，门槛极低。不需要懂代码，不需要配置复杂环境，普通用户也能用。</p><p><strong>人格化设计</strong>：具备独特的性格和表达方式，不像冷冰冰的工具。这让 AI Agent 从工具变成了"伙伴"。</p><p><strong>社区氛围好</strong>：线下聚会、表情包、小龙虾宴，社交属性强。技术产品成功社交化，大大降低了传播门槛。</p><blockquote>"从一个技术产品变成一个大众消费的一个产品。现在火出圈也看来也不并不一定非得是技术上的先进性，它可能踩中了很多风口。" —— 辛宝</blockquote><h3>4. 实际使用体验：从安装到运行</h3><p>三位主播都尝试了安装和使用龙虾，分享了一些实际体验：</p><p><strong>安装门槛</strong>：需要配置 API key、数据库、即时通讯平台等，对普通用户来说还是有一定门槛。但社区提供了大量教程和一键部署方案，降低了难度。</p><p><strong>运行成本</strong>：如果使用 Claude 等付费模型，成本会比较高。但可以选择开源模型或国产模型降低成本。</p><p><strong>实际效果</strong>：龙虾的自主性确实很强，可以自己规划任务、调用工具、完成复杂流程。但也会出现"幻觉"、理解偏差等问题，需要人工介入纠正。</p><p><strong>使用场景</strong>：适合处理重复性任务、信息收集、内容生成等场景。比如定时抓取新闻、生成报告、管理待办事项等。</p><blockquote>"相当于是一个24小时在线待命的，然后随时听从你指令，帮你完成任务的一个 AI 纯的机器人。" —— 瑞丰</blockquote><h3>5. 龙虾的技术架构和核心能力</h3><p>瑞丰详细介绍了龙虾的技术实现：</p><p><strong>核心架构</strong>：基于大模型（如 Claude、GPT-4）+ 工具调用（Function Calling）+ 记忆系统 + 任务规划。</p><p><strong>记忆系统</strong>：龙虾可以记住之前的对话和任务，形成长期记忆。这让它能够理解上下文，处理跨时间的任务。</p><p><strong>工具调用</strong>：龙虾可以调用各种外部工具，如搜索引擎、代码执行器、文件系统、API 接口等。这是它能够完成复杂任务的关键。</p><p><strong>任务规划</strong>：龙虾可以自己拆解任务、制定计划、执行步骤、检查结果。这种自主性是传统 Chatbot 不具备的。</p><p><strong>多平台接入</strong>：通过适配器模式，龙虾可以接入 Telegram、Discord、飞书等多个平台，实现跨平台统一管理。</p><h3>6. 龙虾生态：插件、社区和商业化</h3><p>龙虾的生态发展非常迅速：</p><p><strong>插件系统</strong>：社区开发了大量插件，扩展龙虾的能力。比如天气查询、股票监控、代码审查、文档生成等。</p><p><strong>社区活跃</strong>：GitHub 上有大量 fork 和 PR，Discord 社区每天都有新的讨论和分享。线下聚会也越来越多。</p><p><strong>商业化探索</strong>：已经有团队在探索龙虾的商业化应用，比如企业内部助手、客服机器人、内容生成工具等。</p><p><strong>监管关注</strong>：深圳政府发文规范 AI Agent 应用，说明龙虾已经进入主流视野，开始受到监管关注。</p><h3>7. 龙虾的局限性和挑战</h3><p>三位主播也讨论了龙虾目前存在的问题：</p><p><strong>成本问题</strong>：使用付费模型成本较高，长时间运行可能产生不小的费用。</p><p><strong>可靠性问题</strong>：AI 会出现幻觉、理解偏差、执行错误等问题，不能完全信任。</p><p><strong>安全性问题</strong>：龙虾有很高的权限，如果被恶意利用或出现bug，可能造成严重后果。</p><p><strong>隐私问题</strong>：龙虾需要访问大量个人数据和系统权限，如何保护隐私是个挑战。</p><p><strong>监管风险</strong>：随着政府开始关注和规范，未来可能面临更严格的监管要求。</p><h3>8. 未来展望：AI Agent 的下一步</h3><p>三位主播对 AI Agent 的未来进行了展望：</p><p><strong>多 Agent 协作</strong>：未来可能出现多个 Agent 协同工作的场景，就像一个虚拟团队。辛宝提到了"唐僧团队"的概念：唐僧负责需求拆解，悟空负责代码实现，八戒负责审查，沙僧负责文档核查。</p><p><strong>更强的自主性</strong>：随着模型能力提升，Agent 的自主性会越来越强，能够处理更复杂的任务。</p><p><strong>更低的成本</strong>：开源模型和国产模型的发展，会大大降低 AI Agent 的使用成本。</p><p><strong>更广的应用场景</strong>：从个人助手到企业应用，从内容生成到代码开发，AI Agent 会渗透到各个领域。</p><p><strong>生产力革命</strong>：AI Agent 可能带来10倍、100倍甚至更高的生产力提升，彻底改变工作方式。</p><blockquote>"我们开始考虑十倍以上如何解放百倍的生产力，200倍的生产力可能这可能就是其中的关键之一。"</blockquote><blockquote>"慢点解放，我怕我失业了。"</blockquote><h2>金句摘录</h2><blockquote>"相当于是一个24小时在线待命的，然后随时听从你指令，帮你完成任务的一个
